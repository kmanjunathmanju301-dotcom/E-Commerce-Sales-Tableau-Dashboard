
📊 E-Commerce Sales Dashboard | End-to-End Tableau Project  
🚀 Excited to share my latest E-Commerce Sales Analytics Dashboard project developed using Tableau, where I transformed raw sales data into meaningful business insights through data analysis and interactive visualizations.
📂 Overview
This project focuses on analysing e-commerce sales performance across different markets, product categories, and customer segments to support data-driven business decisions.

🛠️ Tools Used
* Microsoft Excel (CSV)
* Tableau
* Data Cleaning & Transformation
* Exploratory Data Analysis (ED

🔍 Project Steps
1️⃣ Loaded and explored the dataset.
2️⃣ Performed Exploratory Data Analsis (EDA) to identify trends and business opportunities.
3️⃣ Cleaned and prepared data for reporting and visualization.
4️⃣ Built calculated fields and KPIs for business performance tracking.
5️⃣ Designed an interactive Tableau dashboard with filters, KPIs, and trend analysis.
6️⃣ Created project documentation and presentation using Gamma AI.
